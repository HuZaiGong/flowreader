# 仿真翻页（拟物化翻页）评估报告

> 版本: v56 | 日期: 2026-08 | 状态: 评估完成，**暂不实现**

## 背景

ROADMAP v56 要求对「仿真翻页」（页面像实体书一样卷曲、掀起的拟物化动画）作为独立课题重新评估。
v52 已删除过 `SIMULATION` / `CURL` 两个从未渲染的假选项；本报告决定它该不该回来。

## 方案对比

| 方案 | 技术路径 | 成本 | 风险 |
|------|---------|------|------|
| 卷曲角（curl corner） | 单独一个角的手势动画，正文不动 | 低 | 审美廉价，非沉浸 |
| 全页卷曲（fake page curl） | 动画期间把页内容渲染到可变形网格（mesh distortion） | 高 | 需要自定义 GPU 变形或逐帧位图变换 |
| 真实 3D 翻页 | 两页渲染 + 透视变换 + 阴影，跟随手指 | 很高 | 需要 `RenderEffect`/OpenGL 或重写阅读层 |
| **现状：PAGED 横滑** | Compose `HorizontalPager` 原生跟手动画 | 已实现（v54） | 无 |

## 与本项目原则的冲突

1. **性能敏感**（启动 <1s、翻页无卡顿）：卷曲动画期间每帧都要对整页位图做变形。
   离线优先的定位决定了我们不做 GPU 特供；在低端机/大书（数百章）上逐帧变形会直接打穿帧率目标。
2. **克制迭代**（每项功能必须回答"对沉浸式阅读有何帮助"）：
   - 拟物翻页的收益是"纸感"，但对**沉浸阅读**（进入文字、进入心流）是减分项——动画期间无法阅读；
   - 真正被反复要求的是"翻页后能记住位置、翻页不闪屏"，这两者 PAGED/SLIDE 已满足。
3. **内容连续性**：我们的章节是流式文本，不是固定版面页。拟物动画假定"页"是稳定单元，
   而我们的页随字号/行距/字体变化而重新分页——动画与内容生命周期冲突。
4. **无障碍**：TalkBack（v56 走查）下动画翻页无意义且干扰焦点。

## 结论

- **不恢复 UI 入口**：`PageMode` 保持 `SLIDE` / `PAGED` / `NONE` 三个真实实现。
- 若未来要做，优先级顺序应为：① 卷曲角（低投入试探）→ ② 仅在 PAGED 模式下、
  翻页完成后静态渲染"下一页边缘"（静态层，非逐帧变形）→ ③ 重新评估后才考虑 GPU 全页变形。
- 技术前提：Compose `RenderEffect` + `Canvas` 变形稳定可用，且基准设备（minSdk 26 中端机）帧率达标后。
