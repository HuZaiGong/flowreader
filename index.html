离线优先的阅读
只属于你和你的书

FlowReader 是一款 Android 电子书阅读器：没有账号，没有云同步，没有遥测 —— 书和阅读数据只留在这台设备上。

隐私优先

这些「不做」，是写进架构的硬约束

离线优先与隐私不是功能宣传，而是架构级约束 —— 它们决定代码怎么写，而不是等以后再说。

无账号，无云同步

阅读进度、笔记、统计只存在这台设备上。没有账号体系，没有同步，数据不会以任何形式离开设备。

只申请一个权限

全应用仅一个 INTERNET 权限，只供局域网 OPDS 书目与局域网备份互传使用，其余功能全部离线。

无遥测，无崩溃上报

没有统计 SDK，没有崩溃收集。遇到问题时，由你决定是否随报告提供日志。

全应用无 WebView

导入路径处处设上限并防 zip-slip；FTS 查询与 HTML / Markdown 导出一律转义；审计门禁禁止新增 !!。

支持格式

七类格式，一条受限导入管线

单本或批量导入；系统「用其他应用打开」也走同一条管线，且只消费一次，配置变更不会重复导入。

ZIP / CBZ

FB2 与 MOBI 为只读导入，导入时像 EPUB 一样切分章节；带 DRM 的 MOBI / AZW 直接拒绝，不做任何解密。漫画支持单张图片与纯图片 ZIP / CBZ 包。

核心功能

为长读打造

从导入到笔记，从排版到统计，每一步都为沉浸阅读设计。

书库与书单

批量导入、四种排序、网格／列表双视图与「继续阅读」大卡；作者、简介、封面、标签可编辑，自建书单归类。

全库全文搜索

基于 SQLite FTS5 的跨书检索，书名与章节两段结果，分页加载加搜索历史；书内搜索同样可用。

12 套阅读色板

纸白到纯黑，全部通过 WCAG AA 正文对比度自动断言；自定义背景／文字色也带同样的对比度校验。

排版与翻页

12–32sp 字号、行距段距、首行缩进、外部字体；滑动、真实分页、无动画跳转三种翻页，手势全可配且真实生效。

选中与笔记

长按原生选中，5 色高亮加想法备注，选中范围与章节原文精确对应；笔记可导出 Markdown / HTML / 纯文本。

阅读统计

按日记录时长、页数与速度：趋势柱状图、周报月报、最快阅读日，支持每日／每周／每月阅读目标。

局域网 OPDS 与互传

只连内网 OPDS 书目，私有网段之外一律不可达，每次重定向都重新校验；同 WiFi 设备直传备份，随机令牌保护。

备份与更多

备份导入是单个原子事务（上限 200MB）；另有 TTS 朗读、专注模式、定时夜间模式、护眼提醒、主屏 Widget 与决策转盘。
